# Unipicks brand kit (for the student feedback form)

These files use the same logo and colours as the app (`src/components/Logo.jsx`, `public/icon-512-v2.svg`, `src/index.css`).
The logo is a rounded "U" with a dot, like a student with a raised hand: someone who picks.

## Files

| File | Use |
|---|---|
| `form-header-1600x400.png` | Google Form header image (Google's recommended size is 1600 × 400) |
| `unipicks-logo.png` | Logo with the name, transparent background (emails, documents, posters) |
| `unipicks-app-icon-512.png` | Square icon, green background (profile pictures, WhatsApp, QR code centre) |
| `unipicks-app-icon.svg` | Same icon as a vector file (sharp at any size) |
| `unipicks-mark-green.svg` | The "U" mark alone, green, transparent background |

## Colour codes

| Name | Hex | Use |
|---|---|---|
| Unipicks green | `#95BF47` | Main brand colour: buttons, accents, the logo |
| Deep green | `#63903C` | Text links or a darker accent on light backgrounds |
| Ink | `#2E2724` | Main text and the "Unipicks" name |
| Stone | `#70635C` | Secondary text (subtitles, notes) |
| Paper | `#FBFAF8` | Light background |
| Light stone | `#EBE9E5` | Lines and soft panels |
| Cream | `#FCFAF6` | The logo on a green background |

Fonts: **Space Grotesk** (semibold) for headings and the name, **Inter** for body text. Both are free on Google Fonts.

Rule for a calm look: one green accent per page, lots of light space, no extra colours.

## Google Forms: step by step

1. Open the form in edit mode and click the **palette icon** (Customize theme) at the top.
2. **Header:** click *Choose image* → *Upload* → choose `form-header-1600x400.png`.
3. **Colour:** click the **+** under Colour and type `#95BF47`. (Google may pick a colour from the header automatically; set it back to `#95BF47`.)
4. **Background:** choose the lightest option (the light grey or light green).
5. **Text style:** Header **Basic**, Question **Basic**, Text **Basic**.

Google Forms does not allow your own fonts, so "Basic" is the closest clean option.
